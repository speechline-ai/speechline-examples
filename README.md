# Speechline examples

Runnable examples for the Speechline SDKs. Every example is a single script
that talks to `https://dev.speechline.ai` with your API key.

| # | Example | JS | Python |
|---|---------|----|--------|
| 01 | Transcribe a file | [js/src/01-transcribe-file.ts](js/src/01-transcribe-file.ts) | [python/01_transcribe_file.py](python/01_transcribe_file.py) |

## Setup

- API key: sign in at https://dev.speechline.ai, Settings → API Keys, create a key with the `asr` scope.
- JS: see [js/README.md](js/README.md). Needs Node ≥ 22.
- Python: see [python/README.md](python/README.md). Needs Python ≥ 3.9.
